Privacy Policy

Google Apps Script Tools · Last updated: October 18, 2026

Summary. The extension has no server, no analytics and no tracking. Your settings, keys and chat history stay in your browser. Data leaves your browser only when you use a feature that needs it (AI chat or suggestions, GitHub sync, the Apps Script API), and then it goes directly to that service. We never receive, sell or share your data.

1. Who we are

Google Apps Script Tools ("the extension") is a Chrome extension developed by Rubén Darío Sánchez that adds IDE features to the Google Apps Script editor at script.google.com. It is open source under the MIT license.

2. Data the extension handles

DataWhat it is used forWhere it stays
Editor settings, snippets and custom themes Apply your preferences to the Apps Script editor. Your browser (IndexedDB and chrome.storage.sync).
AI preferences: provider, model, response language and your global AI instructions Configure the AI chat and suggestions. chrome.storage.sync.
AI provider API keys Authenticate your requests to the AI provider you chose. This device only (chrome.storage.local, never synced). Never shown to the editor page.
AI chat history per project (may include code) Let you continue a conversation. Up to 30 conversations per project. This device only (chrome.storage.local).
GitHub access token Push and pull your project to the repository you link. This device only (chrome.storage.local).
Repository and branch linked to each Apps Script project Remember where each project syncs. chrome.storage.sync.
Name, email and avatar of the Google account you sign in with Show which account is connected in the panel. chrome.storage.sync.
Google access token Call the Apps Script API on your own projects. Managed by Chrome (chrome.identity); the extension does not store it.
Small UI preferences (dark mode, interface language) Render the popup without flicker. This device only (localStorage).

Data in chrome.storage.sync is synced by Chrome between your own signed-in browsers through your Google account. We cannot access it.

3. Data we do not collect

  • No analytics, telemetry or usage statistics.
  • No browsing history and no activity on sites other than the Apps Script editor.
  • No location, health, financial or payment data.
  • We do not run any server, so we never receive your code, keys, tokens or account details.

4. Connections the extension makes

All requests are made from your browser directly to the service, and only when you use the related feature:

  • Your AI provider (OpenAI, Anthropic, Google Gemini, OpenRouter, Abacus.AI ChatLLM, NVIDIA, or a local model through Ollama or LM Studio): your prompt and the code context you choose (selection, file or project), sent with your own API key. AI is off until you enable a provider and grant Chrome's permission for its domain. The provider's privacy policy applies.
  • GitHub (github.com, api.github.com): sign-in through GitHub's Device Flow and, when you push or pull, the files of your project.
  • Google (script.googleapis.com, www.googleapis.com, oauth2.googleapis.com, script.google.com): the Apps Script API to read and write your own projects after you sign in with Google, your basic profile (name, email, avatar), token revocation when you sign out, and the project export when you download a ZIP.
  • Google Fonts: only if you pick a web font for the code editor, the editor page downloads that font.

5. Google user data (Limited Use)

The extension requests the scopes script.projects, userinfo.email and userinfo.profile only to read and write the Apps Script projects you work on and to show the connected account. The use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. This data is not used for advertising, not sold, and not read by humans.

6. Sharing and selling

We do not sell, rent or transfer your data to third parties. Data reaches an AI provider, GitHub or Google only when you ask for it, as described in section 4, and only to provide that feature. We do not use your data to determine creditworthiness or for lending.

7. How to delete your data

  • Sign out of GitHub or Google from the extension's panels: the GitHub token is deleted and the Google token is revoked.
  • Remove an API key from the AI settings, or delete conversations from the AI chat history.
  • Uninstall the extension: Chrome deletes all of its local data. Synced settings are removed from your Google account's Chrome sync data.
  • To revoke Google access at any time, go to myaccount.google.com/permissions. For GitHub, go to Settings › Applications.

8. Children

The extension is a developer tool and is not directed at children under 13.

9. Changes to this policy

If this policy changes, the date at the top will be updated. Material changes will also be noted in the Chrome Web Store listing.

10. Contact

Questions about this policy: through the support tab of the extension's Chrome Web Store listing or on GitHub.

This policy applies only to the Google Apps Script Tools Chrome extension.
