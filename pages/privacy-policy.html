Privacy Policy

Last updated: 2026-10-18

The short version: GAS Tools has no servers and does not collect personal data. Your settings, API keys and code stay in your browser. Data leaves it only when you use an AI provider, GitHub sync or the Apps Script API, and then it goes directly to that service.

1. Who We Are

GAS Tools ("the Extension") is a Chrome extension developed by Rubén Darío Sánchez that enhances the Google Apps Script editor. The extension is distributed under the MIT License and is available on the Chrome Web Store.

2. Data We Do Not Collect

We do not run any server, so we do not receive or store any of the following:

  • Personal identifiers (name, email, IP address)
  • We do not receive your source code or project files
  • AI API keys or access tokens you configure in the extension
  • Editor settings, themes, or snippets you create
  • Usage analytics or telemetry
  • Browsing history or behavior

3. Where Your Data Is Stored

All extension data stays in your browser. We do not run any server.

  • IndexedDB (local): your snippets, custom themes and editor settings.
  • chrome.storage.sync: non-secret preferences (such as the AI provider and model, language, active theme, your global AI instructions and per-project GitHub repository settings) and the name and email of the Google account you sign in with, which the panel displays. Chrome syncs this data across your own signed-in browsers through your Google account; we cannot access it.
  • chrome.storage.local (this device only, never synced): your AI provider API keys, your GitHub access token and your AI chat history per project, which may include code snippets.
  • localStorage (this device only): small UI preferences such as dark mode and language.

You can delete everything by removing the extension.

4. AI Providers

AI features are off until you enable a provider (OpenAI, Anthropic, Google Gemini, OpenRouter, Abacus.AI ChatLLM, NVIDIA, or a local model through Ollama or LM Studio) and grant Chrome's permission for its domain. Requests are sent from the extension's background service worker directly to that provider with your own API key and contain your prompt plus the code context you select. The background service worker only relays these requests inside your browser; no server of ours is involved and we have no access to their content. The provider's privacy policy applies.

5. Google and GitHub Sign-In

Google sign-in (chrome.identity) is used only to call the Apps Script API on your own projects, for GitHub sync, bulk file deletion and file creation. Google tokens are managed by Chrome.

GitHub sign-in uses GitHub's Device Flow; the resulting token is stored only in chrome.storage.local, and project files are sent to GitHub only when you push or pull. These calls are also made from the extension's background service worker directly to Google and GitHub.

6. Third-Party Services

When you use these features, you interact directly with third-party services. Please review their respective privacy policies:

  • OpenAI Privacy Policy
  • Anthropic Privacy Policy
  • Google Privacy Policy (Gemini, Apps Script API, Google Fonts)
  • OpenRouter Privacy Policy
  • Abacus.AI Privacy Policy
  • NVIDIA Privacy Policy
  • GitHub Privacy Statement

If you pick a web font for the code editor (for example JetBrains Mono), the Apps Script editor page downloads it from Google Fonts. The extension's own interface does not load any external fonts.

7. Limited Use Requirements

The use and transfer of raw or derived user data received from Google Workspace APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

8. Chrome Web Store

The extension is distributed through the Chrome Web Store. Google may collect usage data related to the installation and update of Chrome extensions. Please refer to Google's Privacy Policy for details.

9. Children's Privacy

GAS Tools is a developer tool not directed at children under 13. We do not knowingly collect any information from children.

10. Changes to This Policy

We may update this Privacy Policy from time to time. Changes will be reflected by updating the "Last updated" date at the top of this page. Continued use of the extension after changes constitutes acceptance of the new policy.

11. Contact

If you have questions about this Privacy Policy, you can reach us via GitHub or through the Chrome Web Store listing.

This policy applies solely to the GAS Tools Chrome extension. It does not apply to any third-party services or websites linked from the extension.
